# Fraud Detection & Tabular ML Resources

## Knowledge

- [IEEE-CIS Fraud Detection Competition Discussion & Solutions](https://www.kaggle.com/c/ieee-fraud-detection/discussion)
  The canonical reference for tabular, imbalanced, identity/transaction fraud modeling using gradient-boosted trees.
- [Scikit-learn Guide on Imbalanced Classification & Metrics](https://scikit-learn.org/stable/modules/model_evaluation.html#precision-recall-and-f-measures)
  Authoritative documentation on Precision-Recall AUC vs ROC-AUC and average_precision_score.
- [LightGBM Official Documentation](https://lightgbm.readthedocs.io/en/latest/)
  Primary source on tree building mechanics, `scale_pos_weight`, categorical feature handling, and early stopping.
