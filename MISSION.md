# Mission: Tabular Fraud Detection & Competitive Machine Learning

## Why
Master practical machine learning on time-ordered tabular fraud data so the user can understand, independently evaluate, and contribute to the team's model in the REACT 2026 Datathon and future competitive ML events.

## Success looks like
- Accurately explain why standard ML workflows (e.g. random k-fold, raw ID features) fail on time-ordered tabular data.
- Read and modify feature engineering pipelines that compute strictly-prior rolling statistics without data leakage.
- Understand how LightGBM handles class imbalance, tree boosting, and metric optimization.
- Interpret cross-validation curves, drift signals, and PR-AUC leaderboards to make evidence-based modeling decisions.

## Constraints
- Datathon active deadline: Sep 7, 2026, 23:59 (Dhaka time). Focus on actionable, high-leverage concepts directly tied to the codebase.
- User background: beginner in ML. Focus on visual and intuitive explanations first.

## Out of scope
- Deep neural networks / Transformer architectures for tabular data (rulebook & scale restrictions).
- Unsupervised anomaly detection or generative modeling for fraud.
