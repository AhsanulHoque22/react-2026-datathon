Key Technical Decisions

We trusted only what beat the noise.

Rigor cuts both ways: it's how we found real gains, and how we caught ourselves fooling ourselves.

Validation discipline
Chronological holdout tail
Trained through June 30, tested on July 1–15 (59,465 txns) — strictly ordered by time, mirroring live payment deployment.
Deterministic stable sort (Order integrity)
All expanding baselines depend on previous sequence order. Resolved ~20,000 duplicate timestamps via stable mergesort on (timestamp, transaction_id) to eliminate shuffle drift.
Zero-leakage & noise floor ($\sigma \approx 0.0020$)
Every feature asserts closed='left' via automated checks. Seed variance measured across 5 seeds; only architectural shifts beating it were kept.
Holdout PR-AUC accurately predicted Leaderboard gains with a 2.0× translation ratio.
What we deliberately rejected
Forward-looking features (Peeking ahead)
+0.024 local lift in careless CV — but broke strict temporal-causality rules, so we discarded them completely.
Naive class-reweighting (PR calibration)
scale_pos_weight pushed scores to 1.0, distorting ranking calibration under PR-AUC. Unweighted log-loss produced an immediate +0.026 on the leaderboard.
Monolithic time-decay weighting
Exponential decay degraded split discovery (-0.0031); independent dual-horizon modeling cleanly outperformed it.
Being wrong quickly, on purpose, is how the real gains stayed real.
Feature Density: 220+ candidate features pruned to 160 core causal signals by information density and mutual information.

Pruned from 220+ candidates by information density. Point-in-time causality mechanically asserted.

Appendix B · Model Architecture

Two very different models, one blend.

Trees capture sharp categorical rules; the neural net smooths the boundaries between them.

Dual-Horizon LightGBM
1. Full-Train Horizon (Jan 1 – Jul 15)
882 rounds · 127 leaves · lr 0.02 · feat.frac 0.85 · min_leaf 50
Trained on all 731k rows. Deep trees anchor long-term customer baselines and historical merchant profiles.
2. 90-Day Specialist (Apr 16 – Jul 15)
433 rounds · 63 leaves · lr 0.02 · feat.frac 0.75 · min_leaf 100
Trained only on recent data. Constrained trees adapt directly to rapid summer velocity surges and concept drift.
Why not sample weighting? Exponential time-decay degraded split purity on stable features (-0.0031); independent dual-horizon models cleanly preserve both regimes.
Horizon Blend: 0.48 × Full + 0.52 × 90d → 0.5284 holdout PR-AUC (+0.008)
Tabular ResNet
Continuous Input Representation
158 numerical features normalized via robust quantile scaling; 2 categorical entities mapped to continuous latent embeddings.
3 × Residual Bottleneck Blocks
LayerNorm → Linear(256,512) → GELU → Dropout(0.15) → Linear(512,256) + Skip
Skip connections allow stable gradient flow through deep tabular manifolds without vanishing.
Continuous Manifold Complementarity
Trees create axis-aligned step functions; ResNet learns smooth probability manifolds, catching subtle non-linear boundary anomalies.
Ensemble Blend: 0.88 × Trees + 0.12 × ResNet → 0.5298 holdout PR-AUC

Appendix C · Post-Processing Math

Why propagation works: fraud has siblings.

A confirmed fraud sharply raises the odds its near-in-time neighbors are fraud too.

Audited empirically across 731,942 training transactions in 60-minute sliding windows.
The propagation rule
Pfinal(i) = (1 - w) · Praw(i) + w · avg( PLOO,device(i), PLOO,customer(i) )
w = 0.50 · sliding ±30-minute window (60-min span)
Singleton transactions: 95.3% of test rows have no in-window neighbor and pass through completely unchanged.
Cluster adjustments: Only the 4.7% of transactions sitting inside a real time-cluster get updated.
Zero test leakage: Touches zero test labels and fits zero parameters — purely structural Bayes.
High Throughput: Single-pass sort-and-scan executes in 0.4s across all 262k test transactions.

Noise Floor & Discarded Alternatives
• Empirical Noise Floor ($\sigma \approx 0.0020$):
Measured across 5 random seeds. Every reported architecture milestone cleared this threshold before adoption.
• Graph Neural Networks (GNNs):
Bipartite GraphSAGE/GAT added >45 min training latency and overfit static edges without beating causal tabular baselines.
• CatBoost & XGBoost:
3× slower on 160 causal features; marginal lift (+0.0003) did not justify added deployment complexity.
• Multi-Tier Metamodel Stacking:
Complex secondary blending models suffered severe test drift across the 2-month blind gap and failed OOT tests.
Strict validation discipline prevented overfitting to random leaderboard fluctuations.
