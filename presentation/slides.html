Why two horizons

One advisor has read six months of case files. One has read only the last ninety days. The recent one gets the bigger vote.

Why a neural net at 12%

Appendix C · Compliance

The pipeline refuses to run if a rule is broken.

The rules

  1. Only data before t
  2. Test rows as history — never the label
  3. No random K-fold
  4. Behaviour, not entity IDs

How they hold

  1. Windows are half-open
  2. Totals subtract the current row
  3. Cluster size read before linking

Three assertions, all called

  1. First transaction must be blank
  2. No forward-looking names
  3. No raw IDs, no label

Built, then deleted

Forward-looking features scored +0.024 — our largest single gain.

Against the rules. Deleted, unsubmitted, now blocked by assertion.

One disclosed judgement call: the neighbour window is symmetric, so it reads rows after t. Stated in writing · changes 4.7% of rows · a strictly-past submission scoring 0.55368 was entered alongside.
